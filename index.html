⚙️ GitHub সেটআপ (একবারই লাগবে)
টোকেন শুধু এই ফোনের ব্রাউজারে থাকবে, কোডে বা লিংকে যাবে না।
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate
  2. Repository access: Only select repositories → এই রেপোটা
  3. Permissions → Contents → Read and write
  4. টোকেন কপি করে উপরে বসাও
